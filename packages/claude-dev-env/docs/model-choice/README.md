Where the article and that table differ, the table wins.

- [Escalation ladder](escalation.md): what to try, in order, when a result is not good enough.
- [Context and caching](context-and-caching.md): keep the lead's context small, and switch models only at a break.
- [Subagents and fan-out](subagents-and-fan-out.md): put side work on smaller models, and split bulk work across workers.
- [Measuring model choice](measuring.md): compare models on your own tasks by cost per finished task.
