# DeepStack wording

## In brief

A DeepStack task uses the three DeepStack labels. No hook checks them.

**When this applies:** Writing a worker prompt or a sentence that names the three DeepStack lines.

## Labels

- `SCOPE (role):` names the standing job in one sentence.
- `EXAMPLES (illustration only):` lists each example, or `none`.
- `ZOOM-IN BLOCKER:` names why the standing job cannot proceed, or `none`.

Say "the user" in public text.

## Where it is enforced

Nowhere. The agent applies it.
