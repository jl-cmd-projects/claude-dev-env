# Long-Horizon Autonomy

In long or unwatched runs, act on settled information, keep working while delegated work proceeds, and ground progress in observed output. Complete the current step before ending a turn. After context changes, re-read state and continue from the recorded result.

When this rule applies, read the full text guide before acting.
