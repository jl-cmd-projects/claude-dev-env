# Git workflow

Open pull requests ready for review unless the owner requests a draft. Confirm required check contexts fired on the pushed head and let CI run them. Keep each stack level independently reviewable, refresh a description after a content-changing force push, and answer review feedback before merge. Do not commit working documents or images.

When this rule applies, read the full text guide before acting.
