# ASD-STE100 Language Policy

Use ASD-STE100 Issue 9 clear-writing principles for user-facing text. Write short, complete sentences with one topic each. Use familiar words, direct verbs, and concrete evidence. Consult the official standard for dictionary decisions.

When this rule applies, read the full text guide before acting.
