# ASD-STE100 language policy

**When:** Writing chat, tool narration, or repository prose.

Write short, complete sentences on one topic. Use active voice; lead with conditions; one action per step. Use plain, precise words and stable terms. Expand abbreviations and contractions; name unclear pronouns. Be inclusive; punctuate clearly. Preserve exact labels, identifiers, formulas, titles, interface text. Keep text alternatives and point-of-use context; cut repeats (guide: repeated-points check). Send a result, blocker, or question. Mark injury or death `WARNING`, equipment damage `CAUTION`; state condition then result. Use 20 words per step, 25 per description. Have a human verify accuracy, terms, safety, confidentiality, meaning.

**Enforcement:** none, the agent applies it.
