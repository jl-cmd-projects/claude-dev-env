# Memory Stores Durable Facts

Store only facts that help a fresh session weeks later. Strip dates, issue and pull request numbers, commits, job paths, session IDs, and task numbers from a draft; if nothing useful remains, put it in the task tracker or handoff file. Keep memory entries current.

When this rule applies, read the full text guide before acting.
