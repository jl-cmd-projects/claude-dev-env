# DeepStack wording

**When:** Writing a worker prompt or a line that names the three DeepStack lines.

Use these labels: `SCOPE (role):`, `EXAMPLES (illustration only):`, and `ZOOM-IN BLOCKER:`. Say "the user".

**Enforcement:** none.

**Full text:** [guide](../docs/rule-guides/deepstack-wording.md). Read it when you write the three lines.
