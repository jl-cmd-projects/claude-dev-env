# Correction Lens

This standing rule stays in `rules/` and is never archived. For each user correction, put a control in the highest capable layer: codebase, static analysis, review tooling, skill, then style guide. Open that change in the same run. A repeated correction moves the control up a layer.

When this rule applies, read the full text guide before acting.
