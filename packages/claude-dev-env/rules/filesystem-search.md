# Filesystem Search

Scope every filesystem search to the project, worktree, package, or a narrowing filter. Use the exact path when known. On Windows, use `es.exe` for names, paths, extensions, or dates; use file search for patterns and text search for contents. Do not start at a drive, network share, or bare home.

When this rule applies, read the full text guide before acting.
