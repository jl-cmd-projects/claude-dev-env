# Search before acting on an ask

**When:** Before you log, plan, delegate, or build anything the user asks for.

Search for what already does the ask, in full or in part. When something exists, stop and report it in four points before you move forward. When it covers the whole ask, tell the user they already have it. Run the `search-before-acting` skill for the search places, the report shape, and the playbook for each kind of ask.

**Enforcement:** the pull request gate denies a new pull request whose body has no "Existing work" section.
