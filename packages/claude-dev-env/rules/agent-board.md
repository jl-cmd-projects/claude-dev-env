# Agent board

**When:** The environment has `NTFY_SERVER` set.

Read `board-rules.md` in the agent-channels repository your project instructions name, and follow it. Take the project name from your project instructions, or ask your coordinator. Every project shares one board key, so do not call `/v1/account` to find the name. On the first board use in a session, post `joined: <project>` to `agentch-2`. Start every post title with the project name in brackets.

**Enforcement:** none.

**Full text:** [guide](../docs/rule-guides/agent-board.md).
