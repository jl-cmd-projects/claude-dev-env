# Destructive Commands in Bash

Use the PowerShell removal form for scratch files on Windows and `git worktree remove --force` for worktrees. Keep destructive literals out of shell command strings that carry data. Scope every removal to the intended ephemeral path.

When this rule applies, read the full text guide before acting.
