# GitHub post input rules

For GitHub posts, put logs, tables, diffs, and stack traces in the body. Upload images and other binary artifacts to a durable release, then link that artifact. Do not post job scratch, worktree, or system temp paths. Optimize images before upload.

When this rule applies, read the full text guide before acting.
