# Rules Prose Names Only Hooks That Run

Before describing a hook as active, check that `hooks/hooks.json` or a dispatcher roster invokes it. A file on disk alone does not make a gate run. When a gate retires, remove prose that tells agents to rely on it and name the surviving manual step or live check.

When this rule applies, read the full text guide before acting.
