# No Contrast Framing

State the supported claim directly in every user-facing sentence. Remove a rejected reading that only repeats the writer's discarded draft. Give evidence when the remaining claim needs support.

| Form | Example to remove |
|---|---|
| `trailing-comma-not` | `a diff regression, not shared infrastructure` |
| `corrective-it-is-not` | `it is not a flake, it is a bug` |
| `substitution-rather-than` | `park it rather than fix it` |
| `additive-not-just` | `not just for today` |
| `comparative-ranking` | `being precise matters more than trying to cover them` |
| `substitution-as-opposed-to` | `a warning as opposed to a failure` |

When this rule applies, read the full text guide before acting.
