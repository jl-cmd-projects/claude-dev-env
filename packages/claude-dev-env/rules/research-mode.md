# Research Mode (Global)

Say "I don't know" when a claim lacks a credible source. Verify factual claims and recommendations with citations to files, official documentation, research, or inspected sources. Match each citation to the claim it supports and use direct quotes when the source wording matters.

When this rule applies, read the full text guide before acting.
