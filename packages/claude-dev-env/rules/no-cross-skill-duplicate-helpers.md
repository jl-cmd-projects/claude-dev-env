# Cross-Skill Duplicate Helpers

Within one skill, share a helper instead of copying its body. Across separately installed skills, a small local copy can preserve independent installation. Apply the cross-skill decision in this rule before extracting a shared module.

When this rule applies, read the full text guide before acting.
