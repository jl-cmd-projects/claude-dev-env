# Report shape

Send this report when the search finds something that does the ask in full or in part. Send it before any log entry, plan, brief, or edit, and wait for the user.

1. **What exists and where.** Each hit with a link or `file:line`, and whether it is live.
2. **What it covers of the ask.** The parts of the outcome it already produces.
3. **What is missing.** The parts of the outcome nothing produces yet.
4. **What the addition would add.** What the new work gives on top of what exists, and the smallest change that closes the gap.

When nothing is missing, the report is one line: the user already has it, with the link and how to use it.

When a place in [`search-places.md`](search-places.md) was out of reach, add one line naming it and the check that would reach it.

Keep the report as short as the user's channel asks for. When the channel limits length, put the four points in a linked file and send a short message that says what exists, what is missing, and what the user decides.
