# Plan or log

Use this playbook before you add an ask to a tracker, open an issue or card for it, or write a plan for it.

1. Run the skill steps. Search open and closed tracker entries for the ask first, then the rest of [`../references/search-places.md`](../references/search-places.md).
2. When a tracker entry already names the ask, update that entry and link it. Skip the new entry.
3. When code, config, or a merged pull request already does the ask in full or in part, send the [report](../references/report-shape.md) and wait for the user before you log or plan.
4. When the user says go, log or plan only the missing part. Link each existing piece in the entry or plan, so the reader starts from what is live.
5. When nothing exists, write the entry or plan with one line that names the places searched.
