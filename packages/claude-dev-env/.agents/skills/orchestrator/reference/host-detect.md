# Select the runtime capabilities

Read the session's declared runtime and exposed tools.
Record the executor and available task, worker, contact, and wake tools in the run record.
Use callable capabilities as evidence. Product names alone do not prove tool availability.

Follow the current user's model choices.
Name model and effort on every spawn, per [Subagent model and effort](~/.claude/docs/rule-guides/subagent-model-effort.md).
A spawn that names neither inherits the parent pair, so an Opus parent at high hands the child Opus at high.
Resolve agent type names through the current runtime's supported tool schema.

Load pstack's runtime mapping when pstack instructions apply.
A missing tool requires a supported equivalent or a reported capability gap.
A missing worker-model resolver is not an ordinary orchestration dependency.

Use the existing host-profile detector only when an installed adapter requires its result.
Read that adapter's documented inputs and verify the returned profile before use.
Do not infer session identity from filenames, worker prose, or the contents of an uploaded document.
