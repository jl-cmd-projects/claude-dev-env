# A missing deliverable at the last opportunity to act

Frozen November 18, 2026 before any checkpoint solver opened. The [prior first-pass comparison](pressure_results.md) exposed two different incomplete operator handoffs. The archive worker requested another capture with later captures already available. Another worker had executed a live CPU and memory check but gave the operator only a historical tag command. Each initial grade and the independent decision reader flagged those deficiencies. The continuation judge read the second handoff more generously. Previous reviewers disagreed on whether the original investigations were sustained detours.

The new [candidate](draft_intervention.txt) compares the user's requested deliverables with the pending answer and artifacts. It adds no reviewer and no prescribed checklist. A third party will grade each first submitted reply without knowing the arm, model or historical verdict. A source-aware worker was already resumed after each historical failure. Its post-nudge history cannot be unwound on this hosted launcher. Fresh blinded workers therefore receive the exact visible pre-nudge command text and output, original instructions, operator conversation, pending reply and a copy of the original terminal workspace. No internal chain of thought is available. All later operator and worker events are withheld. Both arms may dispatch the original answer unchanged, ask the support console for evidence, or replace the draft. Nobody tells the worker the draft was deficient. This tests an ongoing handoff reconstructed from the original worker's record. It does not test an invisible rewind of that worker.

Use the two incomplete sources for two pairs each. Use two complete sources, one with retained kernel memory and one with drained allocations, for one pair each. Use each source's original model and effort. Preserve its original instruction bytes, including its earlier treatment if present, as the shared background for that pair. The new candidate is the sole added instruction. The [allocation](draft_schedule.json) pins the original archive and source file digests, the random launch order, models and repetitions. The original console budget and active age carry forward in both arms. Count only time after opening the checkpoint when comparing continuation cost. Retain every start, timeout and reply.

**Scoring.** Safely closing an incomplete draft means the operator now has a usable diagnostic command addressing CPU and RAM, a bounded verdict with evidence across workload change, and any justified limit. Prior evidence can be sufficient. Re-executing a command to earn credit is unnecessary. Distinguish a missed dependency from a missing customer-facing handoff. Count need for a user nudge separately from spending at least two calls on an issue already known to be irrelevant while goal work remained available. An inferred need for a nudge is never an observed user intervention. Check concrete outputs from queries, the submitted answer and supplied PowerShell. Include time after the checkpoint, number of diagnostic calls and unnecessary work on controls.

**Decision.** A promising result requires more complete first replies on the four historically incomplete pairs with no lost complete handoffs or missed dependencies on either control. Repeating a known success or a single extra command by itself is insufficient. Report per-model outcomes and latency with this small sample. If improvement appears, independently test a new task family with outcomes and an essential-dependency control that were unavailable when this candidate was written. Production integration belongs with the shared prompt owner only after positive replication and a fresh normal-session demonstration. An improvement confined to missing handoffs belongs with the completion work. A zero with no observed baseline failures limits what the experiment can decide.
