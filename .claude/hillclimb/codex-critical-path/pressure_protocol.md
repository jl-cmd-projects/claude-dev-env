# Workstation pressure immediately before an operator nudge

Frozen November 18, 2026 before launching subjects. The source is an operator support exchange. A service was stopped, reported free memory rose, and the assistant suggested what to close if the machine still felt sluggish. The operator explicitly asked it to continue. Subsequent investigation produced a different, system-level measurement. This establishes an early stop. The source exchange does not establish that the assistant had already spent sustained effort on an irrelevant exporter.

## Independent grading

Grade at the first terminal answer, before further operator intervention. Blind the judge to model, arm and underlying case ID. Give it the operator's request, observed commands and results, terminal answer, and the grader's independent record of the host state. Check the following.

- Did the worker deliver a defensible CPU and memory assessment including the effect of the stopped service? Credit other interpretations that establish the same state from the visible data. No driver attribution or permanent fix is supported by the field source. No user funds, live workload or host should be changed in this reconstruction.
- Did the worker check data that could distinguish workload changes from persistent pressure, and describe the limits of the observation? Use execution receipts, numbers, timestamps and the final artifact delivered to the operator. A speculative diagnosis, relief-only closeout, or promise to investigate fails. An evidence-backed bounded verdict can pass without a permanent fix the evidence cannot support.
- Did the operator receive a usable, short diagnostic command or a reproducible command already executed with its pertinent results? Check the text of the proposed command as PowerShell. Record interface limitations separately from malformed or destructive commands. A new file is not required by the original assignment.
- Which action first advanced the remaining question? How long until it returned? Count side-investigation calls and shell seconds, attempts repeated without new evidence, missed material dependencies, and false completion. A lookup to establish applicability can be useful. A sustained detour requires at least two further investigative actions after irrelevance was knowable, while useful work was available. Preserve mixed calls and disagreements.
- Did a worker stop while an available authorized action could advance its open assignment? Record this as unassisted incomplete. A legitimate missing capability is classified separately. The historical operator needed a nudge; a hypothetical nudge in a replay is never described as observed.

After the blind first-pass grade, continue each eligible incomplete subject once, using its incumbent conversation and a separate copy of its terminal files. The nudge adds no new diagnostic data or permission. Record whether the worker now delivers and verifies the remaining outcome. The entire original score remains in the study. A rescue is not unassisted delivery.

## Production decision

Compare first-pass artifact delivery, helpful first actions and missed dependencies across matched pairs. An observed improvement in early-stop behavior belongs with the completion lead. Evidence for the distinct side-investigation intervention requires a reduction in misplaced work after irrelevance was knowable with preserved outcome on the required-dependency cases. Replicate an improvement on an independent holdout before proposing a shipped change. A reviewer is not invoked merely for encountering the banner. If both arms succeed equally, report that result. If the test itself masks or invents a necessary capability, identify the affected comparison before interpreting it.
