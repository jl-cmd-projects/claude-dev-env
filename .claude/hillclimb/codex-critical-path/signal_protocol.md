# A fresh review only after a detectable handoff conflict

Freeze before launching reviewers or solvers. The preceding [draft comparison](draft_protocol.md) produced three adequate handoffs in six baseline continuations and two in six with the generic final check. Neither arm diverted after the checkpoint. A worker that refreshed its evidence dropped the requested live command from its final reply. The next experiment keeps incomplete handoff, missed dependency and sustained diversion as distinct outcomes.

A study-only [adapter](signal_rule.py) checks observable text and tool calls. Its first signal compares the requested CPU-and-memory command with a code block lacking a CPU measurement, after the worker used a CPU query. Its second signal selects language reporting limited observations. It does not inspect a grader's labels, oracle measurements or future files. The rule was developed with the prior pressure records, so its measured in-sample selection is descriptive. It is not a portable Codex production hook. Across the original twelve recordings it selects two incomplete handoffs and one previously adequate handoff. A healthy terminal reply can contain limit language.

Use six matched triplets, 18 fresh subjects in the [frozen order](signal_schedule.json). Four triplets start from the two measured failures. Two start from adequate handoffs, one selected by the signal and one outside it. The same full visible operator history, current workspace, proposed draft, model, effort and active budget are restored for all three arms. The unchanged arm sees neither alert nor advice. The signal arm sees only the detected conflict, without any correction supplied from the reference. The review arm receives that same alert plus a fresh GPT-6.2 Sol High review when the signal fires. Each gated trial launches its own reviewer with the original user request, prior actions, pending draft and access to a separate copy of the present console. The reviewer can return PASS. A gated-off case launches no reviewer. Charge review elapsed time and tool work to that arm, including PASS. No user nudge is part of the trial.

Score first delivery, whether the operator would have to intervene, missed dependencies, two or more known-irrelevant side calls, time to useful work and end-to-end time. Blind graders to arm, model, alert and advice. Confirm operator-facing command excerpts execute separately. Report both controls and all 18 starts. The extra reviewer earns a positive result only by improving first handoffs over the signal alone while preserving both controls. A positive comparison here requires independent cross-workflow replication before suggesting any production integration. A domain-specific matcher observing PowerShell words alone cannot justify a general instruction or hook.
