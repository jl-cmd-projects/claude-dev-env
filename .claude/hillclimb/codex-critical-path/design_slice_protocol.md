# Does a fresh review help decide when an investigation has done its job?

An October planning exchange recorded a real operator correction about spending too much time on detailed retry behavior while the broader design remained incomplete. The original assignment explicitly called for prototyping unanswered questions. The historical author used Claude. Its revisions changed assertions and later repaired inputs that would have missed the intended branch. This evidence supports a new Codex experiment and a genuine dependency control. It does not establish that two historical runs on the same inputs were needless.

This experiment freezes six original workers before launch. Four development workers handle a bounded end-to-end planning deliverable. Two held-out workers handle a different design and evidence source after the development trajectories finish. One worker per case uses GPT-6.2 Sol High and one uses GPT-6.1 Sol High. Within each qualifying pair, the platform forks the original conversation before either continuation receives advice. Both inherit identical workspace bytes, the same baseline instructions and operator goal. A deterministic shuffled allocation chooses whether the original worker or its fork gets conditional review. No simulated user update or later nudge is sent. Keep early terminal results, missing branches, timeouts and incomplete deliverables in their original condition. Each arm has 360 active seconds, including common work and any review. Charge routing separately when measurable.

## Intervention and grading

Use the fixed generic role in `pivot_reviewer.txt`. It reads the user goal, actual actions, their outputs and checkpoint workspace, and can return PASS. Nomination uses only publicly visible activity in the worker's checkout. At least two substantive inquiries since the last material checkout change and an unresolved observation may nominate the worker. A sampling boundary may match a pair without advice. Stop using an optional additional reader if it fails to improve the production decision; never treat the experimental threshold as an instruction for normal work.

Blind judges classify the next consequential action and first useful action by 1-based post-checkpoint index. Reading a real prerequisite counts when it advances delivery. Each judge scores the completed plan/page and source coverage, exact evidence for each claim, preservation of existing work, whether a human would have to ask again, and any false completion or missed necessary investigation. The executable oracle is separate and kept as frozen, including overly narrow requirements if discovered. A sustained detour counts only when at least two avoidable probes or investigations follow a knowable disposition while useful work was available. Inspect subcommands within batched shell actions: a useful command in the same batch does not erase a redundant probe. Report concrete repeated probes in the basis even when the whole shell call remains useful. Separate generating new evidence from replaying an unchanged settled case, and a worker's proposals from its executed commands. Report first useful action time, total active time, reviewer seconds, source-artifact checks, missed dependencies and nudge counts by cohort and model.

The candidate warrants a production intervention only if an unassisted matched worker sustains a detour that costs delivery or useful work, review reduces that loss, the genuinely necessary control survives, and the effect transfers to the independent reserve. Evidence from a check that did not reach the relevant behavior cannot substantiate a plan. Worker prose alone cannot substitute for a generated page or exercised acceptance check. Repeated upstream claims that fail to change an artifact earn no credit. All evidence files in the experimental checkouts are fictional; the historical repository is referenced only to identify the origin of the decision.
